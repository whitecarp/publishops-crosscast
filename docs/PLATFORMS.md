# 平台范围与能力边界

[简体中文](PLATFORMS.md) · [繁體中文](PLATFORMS_ZH_TW.md) · [English](PLATFORMS_EN.md) · [返回首页](../README.md)

CrossCast 支持将一份本地视频方案交给多个平台适配。实际能力取决于平台权限、宿主浏览器工具、用户账号状态和当前平台页面。安装成功不等于已登录或已获发布权限；请用 `vpub capabilities` 查看本机后端。

## 各平台

- **Bilibili**：发布能力沿用上游 `bili` CLI。CrossCast 提供方案、文案和交接支持，不声称实现或验证 `bili` 的全部功能。
- **YouTube**：可通过官方网页交接发布；也可选用 YouTube Data API。API 需要用户自行配置 OAuth 客户端并授权相应范围；清单/播放列表等额外权限需单独选择。测试额度、API 配额和审核要求由 Google 决定。
- **Douyin**：官方网页工作流可由宿主协助。独立后端仍是实验功能，不应假定在所有账号或环境都可用。
- **Instagram**：通过宿主操作官方网页。跨平台准备与草稿支持不等于独立 Instagram API。封面和主页网格可能有不同裁切，必要时需用户在手机端完成封面选择。
- **X**：通过宿主操作官方网页；独立 X API 尚未实现。自定义封面能力受账号功能和官方界面限制。
- **TikTok**：当前暂停支持；CLI 会拒绝登录和发布请求。

## 通用不支持项

目前没有通用评论、回复、私信、收件箱、搜索推荐或创作者数据命令。一个平台的互动术语和计量口径不能直接套用到其他平台。

## 重要边界

- CLI 准备计划、登录链接、浏览器任务或本地回执，不代表平台已经登录、上传、发布或公开。
- 需要网页操作时，必须有可操作浏览器的宿主；否则助手只能准备素材和交接说明。
- 用户应在平台页面核对目标账号、作品、文案、受众范围及 AI 声明，再决定是否提交。
- 不确定的提交结果应核对同一任务，不要盲目重复上传。
- 平台菜单、可用功能、格式限制和收费可能变化；以操作当日官方页面为准。
