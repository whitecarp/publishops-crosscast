怎么用

你说一句，AI 帮你准备好

文字由你已有的宿主模型来写；vpub 负责整理草稿、封面、计划和回执。

你说“把这条视频发 B站和 YouTube，标题口语一点。”

AI 处理按平台分别写标题和简介，生成发布草稿，再请你确认平台、账号和公开范围。

你说“封面字太小，Instagram 那版也调一下。”

AI 处理另存一份调整后的封面，原图保留不动；Instagram 使用原视频，不转码。

你说“今晚 8 点发抖音，先排进计划。”

AI 处理写入发布计划，并交给能操作浏览器的助手打开官方网页；扫码或验证码由你完成。排队不等于发布成功。

你说“上次那条到底发出去没有？”

AI 处理查看回执记录，告诉你哪些平台已有回执、哪些还在等待或需要你处理。

平台支持

五个平台，各走各的路

登录默认走官方网页，由你完成扫码或验证码。下表写的是当前真实状态。

平台发布方式说明
Bilibili复用 bili-cli沿用 bili-cli 的登录与投稿能力。
YouTube宿主浏览器 / 官方 API默认宿主浏览器接力；也可选配 YouTube 官方 API。
抖音宿主浏览器接力另有可选的独立后端，目前为实验性。
Instagram宿主浏览器接力保留原视频，不做转码。
X宿主浏览器接力由支持浏览器工具的助手在官方网页上操作。
TikTok暂不支持当前版本未接入。
  • 五个平台的全自动发布尚未完成验收，现阶段请把它当作 alpha 工具。
  • 没有通用的评论管理或数据分析功能。
  • 单独运行的 CLI 只准备交接材料；真正的浏览器操作由支持浏览器工具的 Agent 执行。

三步上手

从安装到第一份草稿

  1. 1

    安装

    需要 Python 3.10–3.12。可以把上面的安装指令交给 AI 助手，或者自己运行：

    python -m pip install "git+https://github.com/whitecarp/publishops-crosscast.git"
  2. 2

    检查环境

    先体检一遍，看看哪些平台能力已经就绪。

    vpub doctor
  3. 3

    准备草稿，由你拍板

    让 AI 先出草稿。发布前由你选定平台、账号、公开范围和审核偏好，之后它只在你授权的范围内行动。

FAQ

常见问题

需要单独的模型 API Key 吗？

不需要。vpub 不内置模型，标题和简介由你已经在用的 Codex、Claude 等宿主模型来写。

它会帮我登录账号吗？

登录默认在宿主能操作的官方网页上进行，扫码或验证码由你本人完成。这个页面不会、也不需要收集任何密钥。

只在终端里运行 vpub，能直接发出去吗？

不能。独立的 CLI 无法操作 Codex 等应用的内置浏览器，它负责准备交接材料；浏览器上的操作需要支持浏览器工具的 Agent 来完成。

进入发布队列就算发布成功了吗？

不算。排队只代表计划已记录，只有拿到平台回执才算发布完成，vpub 会帮你追踪这些回执。

会改动我的原视频和封面吗？

不会。调整封面时原图会保留；发 Instagram 时直接使用原视频，不做转码。

AI 会不会自作主张发到别的地方？

发布前由你选择平台、账号、公开范围和审核偏好，后续操作只在你授权的范围内进行。

支持 TikTok、评论管理或数据分析吗？

暂不支持 TikTok，也没有通用的评论或数据功能。

现在可以放心用于正式发布吗？

当前是 0.3.0 alpha，五个平台的全自动发布尚未完成验收。建议先从草稿和计划开始，每一步都亲自确认。
