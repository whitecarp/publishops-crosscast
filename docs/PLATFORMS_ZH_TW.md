# 平台範圍與能力邊界

[简体中文](PLATFORMS.md) · [繁體中文](PLATFORMS_ZH_TW.md) · [English](PLATFORMS_EN.md) · [返回首頁](../README_ZH_TW.md)

CrossCast 支援將一份本機影片方案交給多個平台適配。實際能力取決於平台權限、宿主瀏覽器工具、使用者帳戶狀態與當前平台頁面。安裝成功不等於已登入或已取得發布權限；請用 `vpub capabilities` 查看本機後端。

## 各平台

- **Bilibili**：發布能力沿用上游 `bili` CLI。CrossCast 提供方案、文案與交接支援，不宣稱實作或驗證 `bili` 的全部功能。
- **YouTube**：可透過官方網頁交接發布；亦可選用 YouTube Data API。API 需要使用者自行設定 OAuth 用戶端並授權相應範圍；清單等額外權限需另行選擇。測試額度、API 配額及審查要求由 Google 決定。
- **Douyin**：宿主可協助執行官方網頁流程。獨立後端仍屬實驗功能，不應假設所有帳號或環境皆可使用。
- **Instagram**：透過宿主操作官方網頁。跨平台準備與草稿支援不等於獨立 Instagram API。封面和個人頁網格可能有不同裁切，必要時需由使用者在手機上完成封面選擇。
- **X**：透過宿主操作官方網頁；獨立 X API 尚未實作。自訂封面能力受帳號功能及官方介面限制。
- **TikTok**：目前暫停支援；CLI 會拒絕登入和發布要求。

## 通用不支援項目

目前沒有通用評論、回覆、私訊、收件匣、搜尋推薦或創作者數據命令。一個平台的互動術語與計量口徑不能直接套用到其他平台。

## 重要邊界

- CLI 準備方案、登入連結、瀏覽器任務或本機回執，不代表平台已登入、上傳、發布或公開。
- 需要網頁操作時，必須有可操作瀏覽器的宿主；否則助手只能準備素材和交接說明。
- 使用者應在平台頁面核對目標帳號、作品、文案、受眾範圍及 AI 聲明，再決定是否提交。
- 提交結果不明時應核對同一任務，不要盲目重複上傳。
- 平台選單、可用功能、格式限制與收費可能變動；以操作當日官方頁面為準。
