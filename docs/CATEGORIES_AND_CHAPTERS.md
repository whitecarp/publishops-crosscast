## YouTube 類別

每支影片依內容選類別，不能因為使用 AI 就一律選科技，也不能默認「人物和博客」。本次 GPT 角色動畫敘事短片已由「人物和博客」改為「電影和動畫」，Studio 已保存；這只是本片的選擇，不是所有影片的預設。

從 0.2.1 起，新 YouTube 方案必須有字串 `category_id`。`vpub init` 刻意不填預設；宿主透過 `metadata request/apply`，結合腳本及當前 Studio／API 類別選項填寫。使用者已指定的類別會保留，文案生成不能擅改。這是機器校驗，不是額外強制人工審核。

- 內置瀏覽器：詳細資訊 → 展開／顯示高級設定 → 類別 → 保存；核對保存狀態及選項。現有影片用 `browser revise` 原地修改，回執必須匹配 `category_id`。
- API：先查所選類別是否可指定，才上傳；讀回類別不符時不能標為驗證成功。此 API 路徑目前為模擬測試。
- 舊版回執可繼續讀取；重新產生或修改方案時補上明確類別，不清空歷史、不重傳影片。

## 抖音章節

實測入口（2026-10-29）：內容管理 → 對應作品 → 懸停「編輯作品」→「添加章節」。已有章節時變成「編輯章節」。直接點主文字可能只進入作品資料編輯頁。

1. 使用同一支成片及字幕的真實時間點；不要從別的版本照搬。
2. 點時間軸、按「手動添加」，填標題後按「確定」。每章完成後，表單會關閉，下一章需要重新打開。
3. 標題最多 12 個 UTF-16 單位；目前 CLI 不自動截字。時間軸顯示與章節列表可能因小數秒取整相差一秒，必須核對列表中的最終整秒。
4. 核對全部章節，再按整體「保存」。若顯示「章節要點正在審核中」，記為已提交待審核，保留作品 ID，不重新提交、不重新上傳。
5. 審核後重新打開「編輯章節」，讀回全部時間、標題及外顯進度條設定，才能記錄已保存驗證。
